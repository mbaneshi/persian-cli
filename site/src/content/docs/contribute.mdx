## Ground rules

1. **Logical order is sacred.** Never fix display by reversing strings or substituting presentation forms.
2. **Cite primary sources**, and link the exact commit you read.
3. **Keep verified and claimed apart.** "The README says" is not "the code does".
4. **Measure.** Every claim about behaviour comes with a reproducible case.
5. **Script-general.** If it only works for Persian, say why, or generalise it.

## How work is organised

- **Phases** are [milestones](https://github.com/mbaneshi/persian-cli/milestones); everything is on the [roadmap board](https://github.com/users/mbaneshi/projects/22).
- **Layers** are `layer/*` labels, following the [problem map](/persian-cli/problem-map/).
- **RFCs** live in [Discussions](https://github.com/mbaneshi/persian-cli/discussions) as `RFC NNNN: …`.
- New here? Try [good first issues](https://github.com/mbaneshi/persian-cli/labels/good%20first%20issue).
